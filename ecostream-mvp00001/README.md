## 📖 Overview

**EcoStream** is a comprehensive e-commerce MVP ecosystem designed to demonstrate the power of AI in retail automation. By integrating **OpenRouter**, the platform automates the most time-consuming parts of running an online store: drafting SEO-ready product listings and managing customer reputation through intelligent sentiment analysis.

## ✨ Key Features

### 🤖 Intelligent Content Engine (Powered by OpenRouter)
*   **Zero-Shot Product Listings:** AI identifies products from images or titles and generates structured, SEO-optimized Amazon-style listings.
*   **Automated Keywords:** Discovers backend search terms to maximize product visibility without manual research.
*   **Vision Integration:** Capable of identify products and features directly from image data.

### 📊 Reputation & Feedback Management
*   **Sentiment Insights:** Automatically categorizes customer reviews as Positive, Neutral, or Negative.
*   **AI Admin Replies:** Generates professional, empathetic responses to customer feedback to improve brand loyalty.
*   **Trend Analysis:** Summarizes recurring themes across all reviews for quick executive decision-making.

### 🏗️ Advanced Architecture
*   **Multi-Storefront Support:** Modular design ready to serve specialized storefronts like *TechBazaar*, *StyleAvenue*, and *HomeHarmony*.
*   **Real-time Analytics:** Full-stack integration ensures that every product change and review update is reflected instantly.

---

## 🛠️ Technical Stack

- **Frontend:** React 19 (Vite), TypeScript, Tailwind CSS, Framer Motion.
- **Backend:** Express Server (Node.js).
- **Database:** Better-SQLite3.
- **AI Middleware:** OpenRouter API (Accessing Llama 3, Gemma, and more).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- An **OpenRouter API Key**

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/ecostream.git
    cd ecostream/ecostream-mvp00001
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Environment Configuration:**
    Create a `.env` file in the root and add your OpenRouter key:
    ```env
    OPENROUTER_API_KEY=your_openrouter_key_here
    ```

4.  **Launch the App:**
    ```bash
    npm run dev
    ```
